Cabinet settings, original controls & credits

Original cabinet controls: Shift thrust, Z reverse, ↑ / ↓ vertical movement, Space fire, X smart bomb, C hyperspace. 5 inserts a coin; 1 / 2 starts a one / two player game. The player buttons above insert the required coins for you. Two players take turns on the same controls.

P pauses, M toggles sound, F enters fullscreen. Progress pauses when this tab is hidden. High scores and cabinet settings save in this browser when local storage is available.

This file contains the emulator and all twelve ROMs. It runs offline with no downloads or server. The MC6809 executes the game ROMs; a separate MC6808-compatible CPU executes the original sound ROM and drives an emulated DAC. Startup diagnostics run automatically before play. ROM bytes are unmodified after the source repository’s original-ROM reconstruction steps.
